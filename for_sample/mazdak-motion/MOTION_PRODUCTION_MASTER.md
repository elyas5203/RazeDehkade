# 1. NARRATIVE & PSYCHOLOGICAL ARCHITECTURE

### The Classroom Context
The players (10–15 teenage boys) believe they are connected to **«مرکز فرماندهی» (Central Command)** via a secure tactical workstation. They are in Week 3 of the mystery investigation. The atmosphere is tense, analytical, and cooperative.

### The Dramatic Turn
The sequence is engineered to create **three distinct psychological stages**:
1. **False Security & Confusion (00:00 – 00:04.5):** "Is the Wi-Fi glitching?" Minor telemetry flicker.
2. **Rising Panic & System Hostility (00:04.5 – 00:19.5):** "The terminal is being hacked in real-time." Sirens, failing diagnostics, alarm klaxons, and structural collapse.
3. **Existential Dread & Personal Threat (00:19.5 – 00:53.5):** The screen dies into complete vacuum silence. Then a rogue entity emerges not as an automated virus, but as a living human stalker: **«مزداک» (Mazdak)**. He reveals that not only has he severed Central Command, but he is eavesdropping on the room's microphones right now.

#### 1. Dynamic Path Failure Countdown (`۱۲ / ۱۲` → `۰۰ / ۱۲`)
*Apply this expression to the `Source Text` property of a text layer in the Diagnostics Panel:*

```javascript
// Dynamic Path Failure Countdown (Frames 270 to 1170)
var startFrame = 270;   // 00:04.50
var endFrame = 1170;    // 00:19.50
var curFrame = timeToFrames(time);

function toPersianDigits(num) {
    var id = ["۰","۱","۲","۳","۴","۵","۶","۷","۸","۹"];
    var s = (num < 10 ? "۰" : "") + num.toString();
    return s.replace(/[0-9]/g, function(w){ return id[+w]; });
}

if (curFrame < startFrame) {
    "مسیرهای امن: ۱۲ / ۱۲";
} else if (curFrame >= endFrame) {
    "مسیرهای امن: ۰۰ / ۱۲ [سقوط کامل]";
} else {
    // Stepped non-linear failure curve
    var progress = (curFrame - startFrame) / (endFrame - startFrame);
    var remaining = 12;
    if (progress > 0.08) remaining = 10;
    if (progress > 0.25) remaining = 8;
    if (progress > 0.45) remaining = 6;
    if (progress > 0.65) remaining = 4;
    if (progress > 0.82) remaining = 2;
    if (progress > 0.95) remaining = 1;
    if (progress >= 1.0) remaining = 0;
    
    // Add micro jitter during breach
    var jitter = (time % 0.15 < 0.04 && remaining > 0) ? " [خطا]" : "";
    "مسیرهای امن: " + toPersianDigits(remaining) + " / ۱۲" + jitter;
```

```javascript
// High-Tech Hollywood Typewriter with Flashing Block Cursor

var cursorChar = " ▌";
var blinkRate = 3.0; // Blinks per second

if (time < startTime) {
    "";
} else {
    var elapsed = time - startTime;
    var charCount = Math.floor(elapsed * charsPerSecond);
    
    // Non-linear pauses for realistic human / terminal transmission
    if (elapsed > 3.2 && elapsed < 4.4) {
        charCount = Math.min(charCount, 24); // Pause after Line 1

    var isBlinking = (Math.sin(time * blinkRate * Math.PI * 2) > 0);
    
    if (charCount < fullText.length) {
        visible + (isBlinking ? cursorChar : "  ");
    } else {
        // Keep blinking cursor after typing is finished
        visible + (isBlinking ? cursorChar : "  ");
    }
}
```
