# 🏛️ راهنمای قرار دادن پوستر «موزه اسرارآمیز» و تنظیم رمزهای گاوصندوق سه‌بعدی

این پوشه (`public/assets/vault/`) محل نگهداری تصاویر و پوسترهای مربوط به **گاوصندوق سه‌بعدی اسلات ۴** است.

## ۱. نحوه جایگزینی پوستر اصلی «موزه اسرارآمیز»
هر زمان پوستر نهایی نمایش حضوری **«موزه اسرارآمیز»** را طراحی کردید:
1. فایل عکس یا پوستر خود را در همین پوشه (`public/assets/vault/`) کپی کنید.
2. در فایل `public/assets/js/vault-3d.js` در بخش `DEFAULT_VAULT_FLAGS`، مسیر عکس(ها) را در آرایه `images` قرار دهید:
   ```js
   {
     id: 'mysterious-museum-finale',
     codes: ['1405', '6062', 'museum', 'موزه'],
     title: '🏛️ دعوت‌نامه ویژه نمایش حضوری «موزه اسرارآمیز»',
     subtitle: 'تبریک دستیاران کارآگاه! شما تمام معماهای پرونده را حل کردید و به برنامه حضوری «موزه اسرارآمیز» دعوت شدید.',
     images: [
       '/assets/vault/mysterious-museum-poster.svg',
       '/assets/vault/mysterious-museum-vip-pass.svg'
     ]
   }
   ```
3. اگر یک عکس در `images` بگذارید، به صورت تک‌پوستر نمایش داده می‌شود؛ و اگر چند عکس بگذارید، اسلایدر و دکمه‌های ورق زدن بین عکس‌ها به صورت خودکار فعال می‌شوند.
