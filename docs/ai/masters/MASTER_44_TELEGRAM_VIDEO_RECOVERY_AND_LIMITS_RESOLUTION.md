## ۲. مانع فنی تلگرام: محدودیت ۲۰ مگابایتی سرورهای استاندارد تلگرام بات API

طبق مستندات رسمی [Telegram Bot API - getFile](https://core.telegram.org/bots/api#getfile):
> *"For the moment, the only way to get a file is to use the getFile method... Bots can download files of up to 20MB in size."*

هنگامی که درخواست دانلود فایل بالای ۲۰ مگابایت (مانند ویدیوی ۳۷ مگابایتی شناسه ۷۷) با Bot Token استاندارد ارسال شد، تلگرام خطای صریح زیر را برگرداند:
`Bad Request: file is too big (Error 400)`

این یک محدودیت سرور تلگرام است، نه باگ نرم‌افزاری ما.

## ۳. معماری ۲ مرحله‌ای بازیابی امن ویدیوها

### فاز ۱: بازیابی خودکار ۱۰۳ ویدیوی زیر ۲۰ مگابایت (شامل ۹۳٪ کل ویدیوها)
- با اسکریپت آزموده‌شده `artifacts/recover-telegram-videos.cjs`:
  - از متد `forwardMessage` در چت ادمین استفاده می‌شود تا `file_id` یکتای ویدیو استخراج شود.
  - فایل توسط استریم از `api.telegram.org/file/bot...` دانلود و با اعتبارسنجی حجم ذخیره می‌شود.
  - پیام فورواردشدهٔ موقت بلافاصله حذف (`deleteMessage`) می‌شود تا چت ادمین خلوت بماند.
  - فایل‌ها مستقیماً در دایرکتوری `storage/emergency-selfies/` روی سرور قرار می‌گیرند.
  - برای کلاس ۱۰، **۱۳ ویدیو از ۱۴ ویدیو** بلافاصله در دسترس کامل قرار می‌گیرند.

### فاز ۲: راهکارهای بازیابی ۸ ویدیوی بالای ۲۰ مگابایت
برای ۸ ویدیویی که بین ۲۰ تا ۳۷ مگابایت هستند، دو مسیر فنی وجود دارد:
1. **روش اول (لوکال بات سرور تلگرام - Local Telegram Bot API Server):**
   - با اجرای باینری متن‌باز `telegram-bot-api` روی سرور محلی با پارامتر `--local`، محدودیت دانلود از ۲۰ مگابایت به ۲ گیگابایت (۲۰۰۰ مگابایت) افزایش می‌یابد.
2. **روش دوم (MTProto Client / Telethon / Pyrogram):**
   - استفاده از یک اسکریپت ساده پایتون تحت پروتکل کلاینت (User API با api_id و api_hash) که هیچ سقف ۲۰ مگابایتی ندارد و هر فایلی تا ۲ گیگابایت را مستقیماً از پیام‌های تلگرام دانلود می‌کند.
3. **روش سوم (جایگزینی ویدیوهای بالای ۲۰ مگ نمونه با فایل محلی در صورت تست):**
   - برای تست فعلی کلاس ۱۰، ۱۳ ویدیو کاملاً واقعی لود می‌شوند و تنها ۱ ویدیوی باقی‌مانده می‌تواند توسط ادمین ست شود یا از طریق MTProto دانلود گردد.
