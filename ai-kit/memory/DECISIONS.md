# تصمیم‌های ماندگار
هنوز تصمیمی برای پروژه مقصد ثبت نشده است.

قالب هر تصمیم:
- شناسه: DEC-001 (شماره بعد از آخرین شناسه واقعی)
- تاریخ و وضعیت: پیشنهادی / پذیرفته / جایگزین‌شده
- مسئله و شواهد:
- گزینه‌ها و علت انتخاب:
- تصمیم و اثر بر قراردادها/ماژول‌ها:
- منبع اختیار: درخواست کاربر یا تصمیم مجاز اجرا
- جایگزین تصمیم: شناسه یا ندارد

پیشنهاد دستیار را تأیید کاربر نام‌گذاری نکن. اصلاح تصمیم با مدخل جدید و پیوند به قبلی انجام شود؛ داده اشتباه را با توضیح اصلاح کن.
