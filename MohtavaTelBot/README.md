# MohtavaTelBot 🤖
**بات تلگرام اختصاصی مدیریت پیام‌های آماده و محتوای ۵ هفته سناریو (راز دهکده)**

## ویژگی‌ها
- 🔒 **محدود به آیدی عددی ادمین (`5490508090`):** هیچ کاربری غیر از این آیدی عددی اجازه استفاده از بات را ندارد.
- 📅 **دسته‌بندی ۵ هفته‌ای:** انتخاب آسان «هفته اول» تا «هفته پنجم» از طریق دکمه‌های کیبورد تلگرام.
- 🔢 **ثبت ترتیبی خودکار (`1, 2, 3, ...`):** هر پیام متنی، عکس، ویدیو، ویس/صوت یا فایلی که فوروارد یا ارسال کنید، به ترتیب شماره مرحله در یک کارت جداگانه برای همان هفته ذخیره می‌شود.
- 📥 **دانلود مستقیم در سرور:** فایل‌های رسانه‌ای (عکس، فیلم، صوت، سند) مستقیماً در پوشه `public/uploads/weekly` سرور دانلود و ذخیره می‌شوند و بلافاصله در پنل ادمین (`سناریوی ۵ هفته‌ای`) قابل استفاده هستند.
- ⚡ **بروزرسانی آنی پنل ادمین:** به محض فوروارد پیام یا فایل به بات، پنل ادمین به‌صورت زنده (Real-time) بروزرسانی می‌شود.

## نحوه اجرا روی سرور (VPS)
بات به‌صورت خودکار همراه با اجرای سرور اصلی (`server.js` / `pm2`) فعال می‌شود.
همچنین در صورت تمایل می‌توانید آن را به‌صورت مستقل نیز اجرا کنید:

```bash
cd ~/RazeDehkade/MohtavaTelBot
npm start
```
یا از ریشه پروژه:
```bash
npm run bot
```
