# SYSTEM / راز دهکده - نسخه ۱.۰
پلتفرم تعاملی سینمایی برای جلسات تربیتی نوجوانان (پرونده‌های کارآگاهی)

این پروژه برای اجرا روی سرورهای محلی (مثل XAMPP) نوشته شده و شامل دو محیط است: 
۱. گل‌فروشی «گلها» (پوشش واقعی)
۲. مرکز فرماندهی و چت مخفی «SYSTEM»

---

### 🛠 پیش‌نیازها و راه‌اندازی

1. نصب بودن **XAMPP** (برای اجرای MySQL).
2. نصب بودن **Node.js**.
3. اجرای MySQL در XAMPP (پورت 3306).
4. در خط فرمان (مسیر پروژه)، دستور `npm install` را اجرا کنید.
5. از دیتابیس مایگریت کنید (ساخت جداول): `npm run migrate`
6. ساخت خودکار ۲۲ کلاس و گروه‌های پایه ۴، ۵ و ۶: `npm run seed`
7. سرور را اجرا کنید: `npm start`
8. سرور روی `http://localhost:3000` اجرا خواهد شد.

## 📂 مسیرهای دقیق فایل‌ها برای پنل «فایل‌های ادمین»

برای قرار دادن ویس‌ها، فیلم‌ها و اسناد از قبل روی سرور (بدون نیاز به آپلود آنلاین در زمان جلسه)، فایل‌ها را در پوشه‌های زیر قرار دهید:

| نوع فایل | مسیر دقیق روی سرور | مثال قرارگیری |
|---|---|---|
| **ویدیو و فیلم‌ها** | `public/media-library/videos/` | `public/media-library/videos/mazdak-intro.mp4` |
| **فایل‌های صوتی و ویس‌ها** | `public/media-library/audio/` | `public/media-library/audio/clue-voice-1.mp3` |
| **تصاویر و عکس‌ها** | `public/media-library/images/` | `public/media-library/images/mill-map.jpg` |
| **اسناد و فایل‌های PDF** | `public/media-library/files/` | `public/media-library/files/document-01.pdf` |

### نحوه استفاده ادمین در پنل:
1. فایل‌های خود را به صورت فیزیکی در پوشه‌های بالا قرار دهید.
2. وارد **داشبورد مدیریت** (`/admin/dashboard.html`) شوید.
3. در منوی اصلی روی گزینه **«مدیریت فایل‌های روی سرور»** کلیک کنید.
4. آدرس دقیق فایل (مثلاً: `videos/mazdak-intro.mp4`)، نوع فایل، و عنوان دلخواهتان را وارد کرده و ثبت کنید.
5. وارد صفحه **اتاق فرمان / چت** (`/admin/chat.html`) شوید.
6. در بخش سمت چپ صفحه چت، لیست فایل‌های ثبت شده را می‌بینید. با یک کلیک ساده، فایل فوراً به جلسه انتخابی ارسال می‌شود.

فرمت‌های شناخته‌شده:

- ویدیو: `mp4`, `webm`, `mov`
- تصویر: `jpg`, `jpeg`, `png`, `gif`, `webp`
- صدا: `mp3`, `wav`, `ogg`, `m4a` و `webm` داخل پوشه `audio`
- بقیه پسوندها به‌شکل فایل دانلودی نمایش داده می‌شوند.

ویدیو و صدا با تگ استاندارد HTML5، آدرس مستقیم روی همان هاست و `preload="metadata"` پخش می‌شوند. Express درخواست‌های Range مرورگر را پشتیبانی می‌کند؛ بنابراین پخش progressive است و لازم نیست کل فایل پیش از شروع پخش دانلود شود.

### تست ۳ دقیقه‌ای کتابخانه مدیا

1. یک MP4 را در `public/media-library/videos/` کپی کنید.
2. سرور را با `npm start` اجرا کنید و وارد داشبورد ادمین شوید.
3. فایل را در بخش **«مدیریت فایل‌های روی سرور»** ثبت کنید.
4. به صفحه چت ادمین بروید و با کلیک روی فایل، آن را ارسال کنید.
5. بررسی کنید کارت فیلم بلافاصله روی برد کاربر ظاهر می‌شود، با کلیک باز می‌شود و پخش را پیش از دانلود کامل آغاز می‌کند.

نکته امنیتی: فهرست کتابخانه فقط برای ادمین لاگین‌شده است؛ نام‌های شامل `../` رد می‌شوند و سرور فقط فایل واقعاً موجود در `public/media-library/` را ارسال می‌کند.
