## 🚀 ویژگی‌های کلیدی سیستم

1. **پوشش فروشگاه گلها (Golha Cover Story):**
   - فروشگاه گل با محصولات سفارشی، سبد خرید، تسویه حساب و تولید اتوماتیک جلسه چت به همراه کد ۶ رقمی بسته.
2. **سناریوی ۵ مرحله‌ای تحویل و انتقال سینمایی:**
   - تایمر معکوس ۳۰ ثانیه‌ای، لایه سیاهی ۱۰ ثانیه‌ای با افکت زنگ در، کارت تحویل داده شد و انتقال خودکار بدون کلیک به درگاه رمزنگاری‌شده.
3. **استریم لایو و کم‌تأخیر صدای میکروفون (WebRTC Pure P2P):**
   - استریم صدای میکروفون لپ‌تاپ جلسه به ادمین با امکان شروع و قطع شنود از هدر پنل ادمین.
4. **آپلود و ارسال واقعی انواع مدیا (Media Uploads):**
   - پشتیبانی کامل از آپلود و ارسال عکس (با تصویر بندانگشتی)، فایل صوتی/ویس (با پلیر HTML5) و فایل‌های عمومی با لینک دانلود مستقیم (`multer`).
5. **سکانس هک مزداک (Cyber Hack Transition):**
   - انیمیشن سینمایی گلیچ، کدهای بارانی ماتریکس، نوار پیشرفت هک سیستم و تغییر تم سایبرپانک.
6. **پشتیبانی از MySQL و ساخت خودکار دیتابیس:**
   - اتصال به دیتابیس MySQL (از جمله زمپ/XAMPP) با ساخت اتوماتیک دیتابیس و جدول‌ها هنگام روشن شدن سرور.

## 🧪 راهنمای گام‌به‌گام و فوق‌العاده ساده تست سناریو

### گام ۱: راه‌اندازی سرور
1. نرم‌افزار **XAMPP Control Panel** را باز کرده و **MySQL** را Start کنید.
2. در ترمینال پروژه دستور زیر را وارد کنید:
   ```bash
   npm start
   ```

### گام ۲: ثبت سفارش در گلها (پوشش اولیه)
1. مرورگر را باز کرده و به آدرس `http://localhost:3000/golha/` بروید.
2. یکی از گل‌ها را انتخاب کرده و دکمه **«+ افزودن به سبد»** را بزنید.
3. دکمه **«تکمیل سفارش و تسویه»** را بزنید و فرم نام و آدرس را پر کنید.
4. روی **«ثبت نهایی سفارش»** کلیک کنید.

### گام ۳: تجربه تایمر معکوس و تحویل بسته
1. وارد صفحه `order-status.html` می‌شوید.
2. تایمر معکوس ۳۰ ثانیه‌ای به صورت بزرگ نمایش داده می‌شود.
3. پس از رسیدن به ۰، صفحه برای ۱۰ ثانیه کاملاً سیاه می‌شود و صدای زنگ در پخش می‌گردد.
4. سپس پیام **«بسته شما تحویل داده شد»** به همراه کد ۶ رقمی بسته به شما نشان داده می‌شود.
5. بدون هیچ کلیکی، سیستم شما را به صفحه **`enter-code.html`** منتقل می‌کند.

### گام ۴: ورود به چت و اجرای هک و شنود صدا
1. در صفحه `enter-code.html` دکمه **«ورود به چت»** را بزنید تا انیمیشن نفوذ سایبری اجرا شده و وارد `/chat.html` شوید.
2. در یک زبانه دیگر مرورگر، وارد `http://localhost:3000/admin/login.html` شوید (یوزر `admin` / پسورد `admin123`).
3. سفارش جدید را در داشبورد ببینید و وارد پنل چت ادمین شوید.
4. دکمه **«🎙️ شروع شنود صدا»** را بزنید تا صدای میکروفون لپ‌تاپ کاربر را آنلاین بشنوید.
5. دکمه **«⚡ تریگر هک مزداک»** را بزنید تا تم و UI صفحه چت کاربر به حالت هک‌شده تغییر کند!
6. از دکمه **📎** برای ارسال عکس، ویس و فایل بین ادمین و کاربر استفاده کنید.
